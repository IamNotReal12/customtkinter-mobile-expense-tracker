## 🚀 Características

- 📱 **Diseño Estilo Móvil:** Contenedor central simulando la interfaz de un dispositivo con barra de estado dinámica y reloj en tiempo real.
- 💾 **Persistencia de Datos:** Almacenamiento local automático de saldos utilizando archivos JSON (`dt/Dtb.json`).
- 📝 **Sistema de Logs:** Registro detallado de acciones y estados de la aplicación mediante la librería estándar `logging`.
- 🔀 **Ventanas Dinámicas:** Interfaz modular que adapta sus títulos y comportamientos según la categoría seleccionada (Configuración, Mensajes, Llamadas, Navegación, Música, etc.).
